01 / SPATIAL RELATIONSHIPS

Keep exposure settings together.

Group shutter, aperture and ISO near the bottom of the live view.

THE ORIGINAL PROBLEM

The captured display spreads shutter speed, aperture and ISO across its lower edge. The fine exposure-meter lines also risk becoming hard to distinguish against bright scenes.

THE DESIGN SOLUTION

Bring the three values into one bottom-centred group and give the data consistent dark backing, without covering the central subject.

Trade-off — Grouping uses live-view space. Test legibility and image obstruction across lighting conditions.

02 / VISUAL SIGNIFIERS

Make settings easier to tell apart.

Use opaque tiles, category edges and a clear selected state.

SELECTEDDistinct highlight

ORIGINAL CONDITION / DOCUMENTED AUDIT

In the captured quick-settings grid, semi-transparent cells sit over the live image and several controls have similar visual weight.

PROPOSED INTERFACE / DOCUMENTED SCREEN

Use opaque tiles for legibility, category edges for orientation, and a separate selected-state treatment. Labels stay visible.

Trade-off — Category cues must remain distinguishable through labels and selection states without relying on colour alone.

04 / 04

INFORMATION ARCHITECTURE

Make recording formats easier to compare.

Remove duplicate badges and add short explanations at the point of selection, while keeping Sony format names intact.

THE ORIGINAL PROBLEM

The captured format list repeats the format name in small stacked badges and in adjacent text. Different badge widths disrupt the left-hand reading edge.

THE DESIGN SOLUTION

Remove repeated badges, align the format names, and add one short compression or workflow cue beneath each option.

WHAT CHANGED IN THE CONTENT
Technical name

XAVC S 4K

Added context in the concept

“Standard (H.264). Highly compatible.”

Whether this helps people choose the intended format is still unknown.

DESIGN EXTENSION / PROGRESSIVE DISCLOSURE

Short descriptions, optional detail

Optional detail explains compression and workflow without extending every menu row. This layer is exploratory, not an archival screen.

WHY THIS MATTERS
Each frame is compressed separately. Editing is generally more responsive, but files can be larger than Long GOP options.

Open question — Do left-aligned names and concise format cues improve correct choices, or mainly make the list quicker to scan? No task results have been collected.

06 / EVALUATION & REFLECTION

What still needs testing

The prototype shows the interaction, but does not establish improvement. Testing needs a defined camera model, firmware and representative tasks.

FORMATIVE STUDY PLAN

Compare tasks on a documented baseline

Measure completion, wrong turns, backtracking, time on task, confidence and recognition of current values—not assumed speed gains.

  1. Read File Format from the menu Can the current value be recognized immediately?
  2. Change the format to XAVC S-I 4K Navigation errors and backtracking
  3. Explain why they chose a format Does contextual help improve understanding?
  4. Inspect ISO, shutter and aperture Does proximity help in live view?
WHAT I BUILT

Four proposed interface changes, a matched menu comparison and an interactive File Format task.

NOT YET PROVEN

Whether any proposal improves recognition, speed, confidence or format understanding.

WHAT I WOULD TEST

The same tasks on an α7S III with its exact firmware, shooting mode and menu configuration recorded, then on the proposal. Compare task steps, errors and recognition.

THE PRINCIPLE EXPLORED

The principle I explored is selective visibility: professional controls can stay intact while the current state becomes easier to recognize. The unresolved question is whether added values help without making the menu too dense.

TECHNICAL REFERENCES

The project names the α7S III. Sony documents a current-settings Main menu on α7S III firmware 3 and later, and describes XAVC S 4K as Long GOP and XAVC S-I 4K as intra-frame recording. These capabilities depend on camera mode and firmware; the exact original screenshot settings remain unverified. The project illustrations are not proof of a limitation in every Sony firmware version. Main menu · File Format guide
